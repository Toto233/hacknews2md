## 保留的实际边界

来源不可编造；文章评论不能冒充 HN 评论；280/180 字最低要求不可批准绕过；微信上传前每条来源的截图要求仍有效。中性/负面关键词的整句人工批准沿用已有明确编辑政策，已批准且未变化的上下文不重复询问。数据库、秘密、URL、用户脏工作区与共享任务锁约束保留。

“发布到微信”在本项目表示创建草稿，不表示群发。生成、修改图片、发布草稿、Astro 推送与业务代码 Git push 有不同完成边界。一次成功发布后，后续局部修改不会自动扩大为另一次外部发布。
